# 🧭 윤송부부일지

**여행일지**(일정표 · 항공편 · 숙소 · 체크리스트)와 **캠핑일지**(준비물 · 식단 계획)를
한 앱에 담은 부부용 기록장입니다. 허브 화면에서 둘 중 하나로 들어갑니다.

폰 홈 화면에 설치해서 앱처럼 쓸 수 있고, 설치 후에는 **인터넷 없이도** 열립니다.
빌드 도구도, 설치할 패키지도 없습니다. 정적 파일뿐입니다.

### 👉 https://dbsgud619-boop.github.io/camping-app/

## 구조

```
index.html (허브)
 ├─ 🗺️ 여행일지  → travel.html
 └─ 🏕️ 캠핑일지  → camping.html
```

허브에서 카드를 눌러 들어가고, 각 화면 위쪽 `←`를 누르면 허브로 돌아옵니다.
두 일지는 **따로 저장**되지만, "함께 쓰기" 방 하나로 **같이** 동기화됩니다
(자세한 내용은 아래 [함께 쓰기](#함께-쓰기-여러-명이-같은-기록-보기) 참고).

## 🗺️ 여행일지

기존에 Next.js로 따로 만들어 쓰던 "여행일지" 웹앱(travel-journal)의 화면 구조 ·
색감 · 문구를 그대로 이 앱으로 옮겼습니다. **원래 웹앱은 그대로 남아 있고
건드리지 않았습니다** — 혹시 몰라 당분간 같이 켜 두는 용도입니다.

### 여행 추가 / 전환

위쪽 툴바의 `+ 새 여행`을 누르면 기간(시작일 · 종료일)과 이름을 입력하는
대화상자가 뜨고, 저장하면 그 기간만큼 날짜별 빈 일정표가 자동으로 만들어집니다.
여러 여행은 알약 모양 탭으로 전환하며, 탭의 `⋯` 메뉴로 이름 변경 · 삭제를
할 수 있습니다.

### 일정표 (일차별 표)

날짜별로 **일차 섹션**이 쌓이고, 섹션마다 시간 · 일정 · 위치 · 첨부 1~2~3
열을 가진 표가 있습니다.

- **+ 일정 추가** — 새 줄이 표 맨 아래 열리고, 시간(시/분 선택) · 분류
  (✈️차량🚗🏨숙박🍽️식사📸관광🛍️쇼핑📌기타) · 일정 내용 · 위치 · 첨부
  1~3(메모 + 사진)을 입력합니다.
- **수정 / 완료** — 섹션을 통째로 편집 모드로 바꿔 여러 줄을 한 번에 고칠 수
  있습니다. 편집 모드에서는 각 줄 왼쪽에 **⠿ 드래그 손잡이**가 나타나 손가락으로
  눌러 끌면 그 날 안에서 순서를 바꿀 수 있고, 오른쪽 **✕**로 그 줄을 지웁니다.
- **첨부 사진** — 썸네일을 누르면 크게 볼 수 있고(라이트박스), 사진은 색깔
  배지(보라 · 초록 · 분홍)로 첨부 1/2/3을 구분합니다.
- **일정이 없는 날** — 표 대신 "등록된 일정이 없어요" 안내가 나옵니다.

각 여행 위쪽에는 **일차 바로가기**(칩 형태로 늘어선 `1일차 2일차 ...`)가 있어
탭 한 번으로 원하는 날짜로 스크롤됩니다. 항공편 · 숙소가 있는 날은 일차
배지 옆에 `✈️`/`🏨` 칩이 붙어 한눈에 보입니다.

### 요약 카드 (AI 자동 생성)

여행 상단(툴바 아래)에 **일차별 요약 카드**가 있으면 그 날의 주요 동선 ·
체크포인트 · 주의사항을 보여줍니다. 카드 자체는 눌러도 안 고쳐지는
읽기 전용이고, 대신 툴바의 **🤖 요약 확인** 버튼이 이 내용을 관리합니다.

- 누르면 그 여행의 모든 날짜를 훑어서, **일정이 마지막으로 바뀐 시각이
  요약이 만들어진 시각보다 늦은 날만** 골라 Claude에게 새로 요약을
  부탁하고 저장합니다. 바뀐 게 없으면 아무 일도 안 하고 "이미 최신"이라고
  알려줍니다.
- 같은 확인을 **1시간마다 화면이 켜져 있을 때 자동으로도** 합니다(조용히,
  바뀐 게 있을 때만 알림).
- 이 기능은 서버가 없는 정적 사이트에서 Claude API 키를 안전하게 쓰기 위해
  Supabase Edge Function(`supabase/functions/travel-summary`)을 하나
  거쳐서 동작합니다 — Supabase 대시보드에 이 함수를 배포하고
  `ANTHROPIC_API_KEY` 시크릿을 등록해야 켜집니다(자세한 내용은 그 폴더의
  코드 주석 참고). 등록 안 해도 나머지 기능은 전부 그대로 동작하고, 이
  버튼만 "함께 쓰기 설정이 안 되어 있다"는 안내와 함께 동작하지 않습니다.

### 항공편 · 숙소 · 체크리스트 (대화상자)

툴바의 `✈️ 항공편`, `🏨 숙소`, `☑️ 체크리스트` 버튼을 누르면 각각 전용
대화상자가 뜹니다.

- **항공편**: 편명 · 항공사 · 출발/도착 일시를 입력하면 해당 날짜의 일차
  배지 옆에 자동으로 표시됩니다.
- **숙소**: 이름 · 체크인 · 체크아웃을 입력하면 묵는 기간의 일차 배지 옆에
  표시됩니다.
- **체크리스트**: 여행 준비물을 목록으로 관리합니다. 줄을 누르면 체크/해제
  두 가지 상태만 있습니다(캠핑일지의 3단계 건너뛰기와 달리 단순하게 뒀습니다).

### 🗺️ 동선 지도

툴바의 `동선 보기`를 누르면 **구글 지도가 화면 안에 실제로 그려집니다.**
전체/일차별로 전환하며 볼 수 있고, 좌표가 있는 일정을 날짜별 색으로 구분한
번호 마커로 표시하고, 마커를 누르면 정보창이 뜨며, 같은 날 일정끼리는 선으로
이어 동선을 보여줍니다. 좌표가 없는 일정은 "위치 정보 없음" 안내에 따로
모아 보여줍니다.

> **원래 웹앱과의 차이 (일부러 단순화한 부분)**: 원래 웹앱은 선택한 하루의
> 동선을 구글 Directions API로 **실제 운전 경로**(도로를 따라 굽은 선, 이동
> 시간 표시)로 그립니다. 이 앱은 구현을 단순하게 유지하려고 항상 **직선**으로
> 지점을 이어서 보여줍니다 — 순서와 위치 관계를 파악하는 용도로는 충분하지만,
> 실제 도로 경로나 이동 시간까지는 보여주지 않습니다.
>
> 지도를 띄우려면 구글 지도 API 키가 필요한데, 원래 웹앱이 이미 클라이언트에
> 공개해 쓰던 키를 그대로 재사용합니다(`maps-config.js`, `NEXT_PUBLIC_` 환경변수라
> 애초에 브라우저에 노출되는 값이라 새로 생기는 위험은 없습니다). 다만 그 키에
> 구글 클라우드 콘솔에서 **HTTP 리퍼러 제한**이 걸려 있고 원래 웹앱 도메인만
> 허용돼 있다면, 이 앱의 깃허브 페이지 주소
> (`https://dbsgud619-boop.github.io/*`)도 허용 목록에 추가해야 지도가 뜹니다.

**사진 첨부**도 서버 업로드 없이 동작합니다. 사진을 고르면 브라우저 안에서
적당한 크기로 줄여(최대 900px, JPEG) 기록 안에 직접 담습니다. 그래서 너무 큰
사진은 자동으로 품질을 낮추고, 그래도 크면 더 작은 사진으로 다시 넣어 달라고
알려줍니다. (사진은 방에 있는 다른 사람에게도 그대로 전달됩니다. 원래
웹앱은 클립보드 붙여넣기 + 서버 업로드 방식이지만, 이 앱은 서버가 없어
파일 선택 + 브라우저 압축 방식을 씁니다)

### 처음 열었을 때

앱에 아직 여행 기록이 없으면, 옮겨온 첫 자료("이집트 2026" 여행 전체)가
**한 번만** 자동으로 들어갑니다. 이미 무언가 있으면(다른 기기에서 먼저
썼거나, 방에서 받아왔거나) 건드리지 않습니다.

## 🏕️ 캠핑일지

캠핑 일정별로 **준비물 체크리스트**와 **끼니별 식단**을 관리합니다.

### 1. 캠핑 추가
`+ 새 캠핑 추가`를 눌러 **시작일 · 종료일 · 장소**를 넣습니다.
넣으면 위쪽에 탭이 하나 생기고, 탭에는 날짜와 **몇 박 며칠**이 자동으로 계산되어 나옵니다.

> 10/3 – 10/5 · 2박 3일

여러 캠핑을 넣으면 탭이 옆으로 늘어나고, 날짜 순으로 정렬됩니다.
탭을 눌러 오가면 되고, 마지막으로 보던 탭은 앱을 껐다 켜도 그대로입니다.

### 2. 준비물 탭

준비물은 두 칸으로 나뉩니다.

| | 어디에 보이나 | 언제 쓰나 |
|---|---|---|
| **공용 준비물** | 모든 일정에 항상 | 텐트, 침낭처럼 매번 챙기는 것 |
| **이번 일정만** | 지금 보고 있는 일정에만 | 낚시대처럼 이번에만 필요한 것 |

입력칸 아래 `공용` / `이번 일정만` 칩으로 어디에 넣을지 고르고 `추가`를 누릅니다.
고른 값은 다음에도 기억하니 매번 바꿀 필요 없습니다.

**새 일정을 만들면 공용 준비물이 그대로 따라 들어갑니다.** 체크만 비워진 채로요.
그래서 갈 때마다 목록을 다시 적을 필요가 없습니다.

한 줄에서 할 수 있는 것:

- **줄 아무 데나 누르면 상태가 한 칸씩 돕니다.**

  | 누른 횟수 | 표시 | 뜻 |
  |---|---|---|
  | 1번 | ✓ 초록 체크 | 챙김 |
  | 2번 | ▲ 빨간 세모 (글씨 흐리게) | **이번엔 안 챙김** |
  | 3번 | 표시 없음 | 처음으로 |

  `이번엔 안 챙김`으로 둔 항목은 **`3 / 8 챙김`의 분모에서 빠집니다.**
  공용 목록에는 남겨두되 이번 캠핑만 건너뛸 때 쓰세요.
  (집 근처라 랜턴은 안 챙긴다거나, 글램핑이라 텐트가 필요 없을 때)
  막대 옆 `▲ 2`는 이번에 건너뛴 개수입니다.

  이 상태는 **일정마다 따로** 남습니다.
  가평에서 텐트를 챙겼다고 양양 일정까지 체크되지 않습니다.
- **✎** — 이름 수정. 공용 항목을 고치면 모든 일정에서 같이 바뀝니다.
- **✕** — 삭제. 공용 항목은 다른 일정에서도 사라지므로 한 번 물어봅니다.
- **공용으로** — `이번 일정만` 항목을 공용으로 옮깁니다. 체크해둔 상태는 그대로 따라갑니다.

위쪽 막대와 `3 / 10 챙김`은 공용과 일정 전용을 합쳐서 세고,
`이번엔 안 챙김`으로 둔 항목은 빼고 셉니다.
같은 이름을 또 넣으면 알려주고 넘어갑니다.

### 3. 식단 탭

#### 메뉴 꾸러미 (끌어다 놓기)

표 위에 이 캠핑에서 먹을 메뉴를 적어 둘 수 있습니다. 적으면 **글자 길이에 맞는
작은 칸**으로 하나씩 생깁니다.

```
[ 이 캠핑에서 먹을 메뉴 (예: 김치찌개) ]  [추가]

 김치찌개 ✕   삼겹살 ✕   라면 ✕   된장찌개 ✕
```

메뉴를 **꾹 눌러 아래 표의 칸으로 끌어다 놓으면** 그 칸에 들어갑니다.
끌고 가는 동안 손가락 위에 메뉴가 따라다니고, 놓을 칸에 주황 테두리가 켜집니다.
빗금 친 `-` 칸에 놓아도 됩니다. 빗금이 풀리고 메뉴가 들어갑니다.

- 이미 뭔가 적힌 칸에 놓으면 **덮어씁니다.**
- 칸이 아닌 곳에 놓으면 아무 일도 없습니다.
- `✕` 를 누르면 그 메뉴를 목록에서 지웁니다. (표에 이미 넣은 건 그대로 남습니다)
- 메뉴 목록은 **일정마다 따로입니다.** 가평에 적은 메뉴가 양양에 끼어들지 않습니다.
  새 일정은 빈 목록으로 시작합니다.
- 목록은 표 위에 붙어 있어서 아래로 스크롤해도 계속 잡을 수 있습니다.

#### 표

일차가 **가로로 세 칸씩** 놓인 표입니다.
끼니 이름은 맨 왼쪽에 한 번만 적혀 있고, 일차 칸에는 빈칸만 있습니다.

|  | **1일차**<br>10/3 (토) | **2일차**<br>10/4 (일) | **3일차**<br>10/5 (월) |
|---:|---|---|---|
| **아침** | | | |
| 아점 | | | |
| **점심** | | | |
| 점저 | | | |
| **저녁** | | | |
| 야간 | | | |

**아침·점심·저녁**은 굵게, 곁들이는 **아점·점저·야간**은 흐리게 두어
주 끼니가 먼저 보입니다.

**아점·점저·야간은 `-` 가 미리 들어가 있습니다.** 보통 안 먹는 끼니라
빗금 친 회색 칸으로 눕혀 두었습니다. 먹기로 했으면 그 위에 적으면 됩니다.
아침·점심·저녁은 빈칸으로 둡니다.

칸에 **`-` 를 적으면 그 끼니는 건너뛴다는 뜻**이 되어 빗금 회색으로 바뀝니다.
`--` 처럼 여러 개를 적어도 같게 봅니다.
글자를 적으면 회색이 풀리고 주황 표시로 바뀝니다.

`-` 를 지워서 빈칸으로 두면 **지운 대로 남습니다.** 다시 채워 넣지 않습니다.

3일이 넘는 일정이면 표가 아래로 이어집니다. 남는 일수가 있어도(예: 4박5일의
마지막 하루) **늘 세 칸 너비**로 그려서 칸이 넓어지지 않습니다.

적으면 바로 저장됩니다. (따로 저장 버튼 없음)
내용을 적은 칸은 왼쪽에 주황 줄이 생기고, 일차 머리말의 `2/6`으로
그날 몇 끼를 정했는지 보입니다. `-` 도 "안 먹기로 정했다"로 쳐서 셉니다.

## 폰에 설치하기

폰 브라우저로 앱 주소(맨 위 링크)를 열고 홈 화면에 추가하면 됩니다.

- **안드로이드 크롬** — 주소창 옆 `⋮` 메뉴 → `앱 설치` 또는 `홈 화면에 추가`
- **아이폰 사파리** — 아래 공유 버튼 → `홈 화면에 추가`

홈 화면 아이콘으로 열면 주소창 없이 앱처럼 뜨고, 한 번 연 뒤에는
**비행기 모드나 캠핑장 산속에서도** 그대로 열립니다.

### 컴퓨터에서 확인하려면

```bash
cd camping_app
npx serve .
# 또는
python -m http.server 4173
```
브라우저에서 `http://localhost:4173`을 엽니다.
`localhost`는 https가 아니어도 설치·오프라인 기능이 동작합니다.

## 함께 쓰기 (여러 명이 같은 기록 보기)

기본은 이 폰에만 저장합니다. 켜려면 **한 번만** 아래를 해두면 됩니다.
**여행일지 · 캠핑일지 모두 방 하나로 함께 맞춥니다** — 두 화면 중 아무 데서나
방을 만들거나 들어가면 됩니다.

### 준비 (처음 한 번)

1. [supabase.com](https://supabase.com) 에서 새 프로젝트를 만듭니다 (기존 프로젝트에
   얹어 써도 됩니다 — [`supabase.sql`](supabase.sql)은 `camp_` 로 시작하는
   테이블/함수만 만들어서 다른 것과 안 섞입니다).
2. **SQL Editor** 에 [`supabase.sql`](supabase.sql) 을 통째로 붙여넣고 Run.
3. **Project Settings → Data API** 에서 `Project URL` 과 `anon public` 키를 복사해
   [`supabase-config.js`](supabase-config.js) 에 채웁니다.
4. 커밋하고 푸시하면 앱 위에 **함께 쓰기 막대**가 생깁니다.

비워 두면 막대가 안 보이고, 앱은 지금처럼 혼자 쓰는 대로 동작합니다.

> 기존 Supabase 프로젝트에 얹을 때는 **그 프로젝트의 다른 테이블이 anon 키로
> 열려 있지 않은지** 먼저 확인하세요. anon 키는 이 앱처럼 브라우저에 그대로
> 내려가는 공개용 키라, RLS(행 단위 보안)로 잠겨 있지 않은 테이블은 이 키를
> 아는 누구나 읽을 수 있습니다.

### 쓰는 법

- **새 방 만들기** — 지금 이 폰의 기록(여행일지 · 캠핑일지 모두)을 그대로 올리고
  방 코드를 줍니다. (예: `K7QM-3XRA-9TPF-WZ2H`)
- **초대하기** — 방에 들어간 뒤 이 버튼을 누르면 **초대 링크**가 나옵니다.
  카톡 등으로 보내면 받은 사람이 링크를 열고 확인만 누르면 같은 방에 들어옵니다.
  방 코드도 함께 담겨 있어 직접 입력해도 됩니다.
- **방 코드 넣기** — 받은 코드를 넣으면 **내 기록과 방 기록을 모두 합칩니다.**
  어느 쪽도 지워지지 않습니다.
- 고치면 곧 올라가고, 앱을 열거나 다시 켤 때마다 상대 내용을 받아옵니다.

> 초대 링크의 코드는 주소의 `#` 뒤에 붙습니다. `#` 뒤는 서버로 전송되지 않아
> 접속 기록에 코드가 남지 않습니다. 들어오고 나면 주소에서도 지웁니다.

**다른 사람이 앱으로 설치하려면** 링크를 폰 브라우저로 열고 홈 화면에 추가하면 됩니다.
아이폰은 홈 화면 앱과 사파리의 저장 공간이 따로라, **먼저 설치하고 앱 안에서
방 코드를 넣는 순서**가 확실합니다. (초대 메시지에 코드가 같이 들어 있습니다)

### 어떻게 합치나

지난번에 맞춘 내용을 기준 삼아 **내 변경과 상대 변경을 둘 다 살립니다.**

| 상황 | 결과 |
|---|---|
| 나는 캠핑 준비물, 상대는 여행 일정을 고침 | 둘 다 남음 |
| 상대가 항목을 새로 넣음 | 내 것에 더해짐 |
| 한쪽이 항목을 지움 | 지워진 채로 유지 (되살아나지 않음) |
| **같은 칸**을 동시에 고침 | 나중에 고친 쪽이 남음 |
| 캠핑일지 화면만 열어 둠 | 여행일지 기록은 그대로 지나감 (안 지워짐) |

인터넷이 없으면 그냥 이 폰에 쌓아 두었다가, 연결되면 그때 맞춥니다.

### 안전장치

- 방 코드는 서버에 **저장되지 않습니다.** 코드의 해시만 둡니다.
- 테이블은 직접 접근이 막혀 있고, 정해진 함수 셋으로만 드나듭니다.
- 처음 방에 연결하기 직전의 기록을 따로 백업해 둡니다.
- 방에서 나가도 **이 폰의 기록은 그대로 남습니다.**

> 방 코드가 곧 열쇠입니다. 코드를 아는 사람은 누구나 볼 수 있으니
> 아무에게나 보내지 마세요.

## 알아두면 좋은 것

- **기록은 이 폰 안에만** 있습니다 (브라우저 localStorage). "함께 쓰기"를 켜지
  않으면 서버로 아무것도 보내지 않습니다.
  브라우저 데이터를 지우거나 앱을 삭제하면 기록도 같이 지워집니다.
- 공용 준비물 목록은 일정과 따로 저장됩니다. 일정을 전부 지워도 공용 목록은 남습니다.
- 기기끼리 동기화되지 않습니다 (함께 쓰기를 켜지 않았다면). 폰에 적은 건 폰에만 남습니다.
- 캠핑을 삭제하면 그 캠핑의 준비물과 식단도 함께 사라집니다. (지우기 전에 한 번 물어봅니다)
- 여행을 삭제하면 그 여행의 일정 · 항공편 · 숙소 · 체크리스트가 모두 사라집니다.
- 장소 이름은 `수정` 버튼으로 바꿀 수 있습니다. 날짜를 바꾸려면 새로 만드는 게 안전합니다.
  (날짜를 옮기면 이미 적어둔 식단/일정이 어느 날 것인지 어긋나기 때문입니다)
- 여행일지의 사진 첨부는 한 장당 대략 350KB 이하로 줄여서 넣습니다. 원본 화질이
  아니라 "기록에 남는 정도"입니다.
- **원래 travel-journal 웹앱은 그대로 있습니다.** 이 앱은 그 자료를 복사해온
  것이지, travel-journal 을 지우거나 대체하지 않았습니다.

### 고치고 싶을 때

  줄을 빼거나 더하면 화면도 저장도 알아서 따라갑니다.
  ```js
  const MEALS = [
    { key: 'morning', label: '아침', hint: '', main: true },
    ...
  ];
  ```
- **일정 분류를 바꾸려면** — `app-travel.js` 맨 위 `CATEGORIES` 배열을 고칩니다.
- **색을 바꾸려면** — `style.css` 맨 위 `:root` 변수만 고치면 전체가 바뀝니다.
- **고친 게 폰에 반영이 안 되면** — 위 `고친 내용을 폰에 반영하기`를 보세요.
