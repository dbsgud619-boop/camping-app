# 🏕️ 캠핑 준비

캠핑 일정별로 **준비물 체크리스트**와 **끼니별 식단**을 관리하는 개인용 앱입니다.
폰 홈 화면에 설치해서 앱처럼 쓸 수 있고, 설치 후에는 **인터넷 없이도** 열립니다.

빌드 도구도, 설치할 패키지도 없습니다. 파일 6개가 전부입니다.

---

## 쓰는 법

### 1. 캠핑 추가
`+ 새 캠핑 추가`를 눌러 **시작일 · 종료일 · 장소**를 넣습니다.
넣으면 위쪽에 탭이 하나 생기고, 탭에는 날짜와 **몇 박 며칠**이 자동으로 계산되어 나옵니다.

> 10/3 – 10/5 · 2박 3일

여러 캠핑을 넣으면 탭이 옆으로 늘어나고, 날짜 순으로 정렬됩니다.
탭을 눌러 오가면 되고, 마지막으로 보던 탭은 앱을 껐다 켜도 그대로입니다.

### 2. 준비물 탭

준비물은 두 칸으로 나뉩니다.

| | 어디에 보이나 | 언제 쓰나 |
|---|---|---|
| **공용 준비물** | 모든 일정에 항상 | 텐트, 침낭처럼 매번 챙기는 것 |
| **이번 일정만** | 지금 보고 있는 일정에만 | 낚시대처럼 이번에만 필요한 것 |

입력칸 아래 `공용` / `이번 일정만` 칩으로 어디에 넣을지 고르고 `추가`를 누릅니다.
고른 값은 다음에도 기억하니 매번 바꿀 필요 없습니다.

**새 일정을 만들면 공용 준비물이 그대로 따라 들어갑니다.** 체크만 비워진 채로요.
그래서 갈 때마다 목록을 다시 적을 필요가 없습니다.

한 줄에서 할 수 있는 것:

- **줄 아무 데나 누르면 상태가 한 칸씩 돕니다.**

  | 누른 횟수 | 표시 | 뜻 |
  |---|---|---|
  | 1번 | ✓ 초록 체크 | 챙김 |
  | 2번 | ▲ 빨간 세모 (글씨 흐리게) | **이번엔 안 챙김** |
  | 3번 | 표시 없음 | 처음으로 |

  `이번엔 안 챙김`으로 둔 항목은 **`3 / 8 챙김`의 분모에서 빠집니다.**
  공용 목록에는 남겨두되 이번 캠핑만 건너뛸 때 쓰세요.
  (집 근처라 랜턴은 안 챙긴다거나, 글램핑이라 텐트가 필요 없을 때)
  막대 옆 `▲ 2`는 이번에 건너뛴 개수입니다.

  이 상태는 **일정마다 따로** 남습니다.
  가평에서 텐트를 챙겼다고 양양 일정까지 체크되지 않습니다.
- **✎** — 이름 수정. 공용 항목을 고치면 모든 일정에서 같이 바뀝니다.
- **✕** — 삭제. 공용 항목은 다른 일정에서도 사라지므로 한 번 물어봅니다.
- **공용으로** — `이번 일정만` 항목을 공용으로 옮깁니다. 체크해둔 상태는 그대로 따라갑니다.

위쪽 막대와 `3 / 10 챙김`은 공용과 일정 전용을 합쳐서 세고,
`이번엔 안 챙김`으로 둔 항목은 빼고 셉니다.
같은 이름을 또 넣으면 알려주고 넘어갑니다.

### 3. 식단 탭

일차가 **가로로 세 칸씩** 놓인 표입니다.
끼니 이름은 맨 왼쪽에 한 번만 적혀 있고, 일차 칸에는 빈칸만 있습니다.

|  | **1일차**<br>10/3 (토) | **2일차**<br>10/4 (일) | **3일차**<br>10/5 (월) |
|---:|---|---|---|
| **아침** | | | |
| 아점 | | | |
| **점심** | | | |
| 점저 | | | |
| **저녁** | | | |
| 야간 | | | |

**아침·점심·저녁**은 굵게, 곁들이는 **아점·점저·야간**은 흐리게 두어
주 끼니가 먼저 보입니다. 보조 칸에는 `보조 식사`라고 흐린 글씨가 있습니다.

3일이 넘는 일정이면 표가 아래로 이어집니다.
4박5일이면 `1~3일차` 표 아래에 `4~5일차` 표가 붙는 식입니다.

적으면 바로 저장됩니다. (따로 저장 버튼 없음)
내용을 적은 칸은 왼쪽에 주황 줄이 생기고, 일차 머리말의 `2/6`으로
그날 몇 끼를 정했는지 보입니다.

## 폰에 설치하기

앱 주소는 여기입니다.

### 👉 https://dbsgud619-boop.github.io/camping-app/

폰 브라우저로 위 주소를 열고 홈 화면에 추가하면 됩니다.

- **안드로이드 크롬** — 주소창 옆 `⋮` 메뉴 → `앱 설치` 또는 `홈 화면에 추가`
- **아이폰 사파리** — 아래 공유 버튼 → `홈 화면에 추가`

홈 화면 아이콘으로 열면 주소창 없이 앱처럼 뜨고, 한 번 연 뒤에는
**비행기 모드나 캠핑장 산속에서도** 그대로 열립니다.

### 컴퓨터에서 확인하려면

```bash
cd camping_app
npx serve .
# 또는
python -m http.server 4173
```
브라우저에서 `http://localhost:4173`을 엽니다.
`localhost`는 https가 아니어도 설치·오프라인 기능이 동작합니다.

## 고친 내용을 폰에 반영하기

파일을 고친 뒤 푸시하면 1~2분 안에 Pages에 반영됩니다.

```bash
cd camping_app
git add -A
git commit -m "무엇을 고쳤는지"
git push
```

**중요** — 화면이 안 바뀌면 캐시 때문입니다.
`service-worker.js` 첫 줄의 버전을 올리고 다시 푸시하세요.

```js
const CACHE_NAME = 'camping-app-v2';   // v1 → v2 로
```

이 숫자를 올리면 폰이 오래된 파일을 버리고 새로 받아옵니다.

## 알아두면 좋은 것

- **기록은 이 폰 안에만** 있습니다 (브라우저 localStorage). 서버로 아무것도 보내지 않습니다.
  대신 브라우저 데이터를 지우거나 앱을 삭제하면 기록도 같이 지워집니다.
- 공용 준비물 목록은 일정과 따로 저장됩니다. 일정을 전부 지워도 공용 목록은 남습니다.
- 기기끼리 동기화되지 않습니다. 폰에 적은 건 폰에만 남습니다.
- 캠핑을 삭제하면 그 캠핑의 준비물과 식단도 함께 사라집니다. (지우기 전에 한 번 물어봅니다)
- 장소 이름은 `수정` 버튼으로 바꿀 수 있습니다. 날짜를 바꾸려면 새로 만드는 게 안전합니다.
  (날짜를 옮기면 이미 적어둔 식단이 어느 날 것인지 어긋나기 때문입니다)

## 파일

```
camping_app/
├─ index.html          화면 뼈대
├─ style.css           어두운 숲 색 테마
├─ app.js              전부 여기에 (날짜 계산, 탭, 준비물, 식단, 저장)
├─ manifest.json       설치 정보 (이름, 아이콘, 색)
├─ service-worker.js   오프라인 캐시
└─ icon.svg            텐트 아이콘
```

### 고치고 싶을 때

- **끼니 종류를 바꾸려면** — `app.js` 맨 위 `MEALS` 배열을 고칩니다.
  줄을 빼거나 더하면 화면도 저장도 알아서 따라갑니다.
  ```js
  const MEALS = [
    { key: 'morning', label: '아침', hint: '예: 토스트, 커피' },
    ...
  ];
  ```
- **색을 바꾸려면** — `style.css` 맨 위 `:root` 변수만 고치면 전체가 바뀝니다.
- **고친 게 폰에 반영이 안 되면** — 위 `고친 내용을 폰에 반영하기`를 보세요.
